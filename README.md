# dyslexiapp

DyslexiApp - A dyslexia-friendly app for reading and spelling

# Target Audience
- Dyslexic kids who can't read and spell

# Problems
- Insufficient dyslexia-related reading material
- Dyslexic kids gets left behind by their peers

# Features
## Reading and Spelling Exercise
- Measure reading fluency with alphabet exercise using text-to-speech feature
- All alphabet, 10 exercises for each alphabet
- Spelling exercise for each alphabet

## Flashcards
- Attractive flashcard to enhance alphabet recognition

## Text Recognition (OCR)
- Ease up dyslexic kids to read books by scanning text on books
- Recognized text converts to speech (becoming audiobook)


# Tech Stacks
- Flutter + Dart (base framework and language)
- GetX (State management)
- Firebase (Database, auth)
